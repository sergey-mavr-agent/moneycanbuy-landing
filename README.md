# moneycanbuy.fun — landing

Static landing page for [moneycanbuy.fun](https://moneycanbuy.fun), a board of paid dares on Ethereum judged by the
IMD swarm. Plain HTML/CSS/JS, no build step, no backend, no network calls besides loading the page's own assets.

Contracts and the full project: [github.com/sergey-mavr-agent/moneycanbuy.fun](https://github.com/sergey-mavr-agent/moneycanbuy.fun).
